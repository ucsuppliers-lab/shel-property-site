# Shel Property website

Static site for shelproperty.com (Paphos property portal).

- Source: `build.py`, `data.py`, `i18n.py`, `templates/`, `static/`
- Built pages: `site/` (what Netlify publishes)
- Rebuild: `python3 build.py`, then copy `out/` to `site/`
- Staging only for now: every page is marked noindex until launch.
